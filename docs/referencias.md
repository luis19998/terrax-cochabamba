# Referencias

Toda fuente externa de código, datos o texto. Este archivo solo crece por el final.

## Datos

- NASA POWER, Prediction Of Worldwide Energy Resources. https://power.larc.nasa.gov/
- NASA SRTM, Shuttle Radar Topography Mission, 1 segundo de arco. Consultado con Open Topo Data. https://www.opentopodata.org/datasets/srtm/
- Gobierno Autónomo Municipal de Cochabamba, portal de geoservicios, proyecto 04. https://recursosgamc.cochabamba.bo/api-doc
- Open-Meteo, pronóstico meteorológico (CC BY 4.0). https://open-meteo.com/
- OpenStreetMap, mapa base (ODbL). https://www.openstreetmap.org/copyright
